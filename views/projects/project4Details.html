Projet 4 Laravel

Application Laravel — Plateforme de gestion de livres

Réalisé en 2026  |  Groupe 1 AWS re/Start

Description du projet

Ce projet consiste en le développement d'une plateforme web complète de gestion de livres construite avec le framework PHP Laravel. L'application propose une interface moderne, intuitive et réactive, permettant aux utilisateurs de gérer facilement un catalogue de livres.

L'application intègre un système d'authentification sécurisé, une gestion CRUD (Créer, Lire, Modifier, Supprimer) des livres, ainsi qu'un tableau de bord administrateur. Le tout est déployé sur une infrastructure AWS pour assurer disponibilité et scalabilité.

Fonctionnalités principales

  • Authentification & gestion des rôles (admin / utilisateur)
  • CRUD complet : ajout, modification, suppression de livres
  • Recherche et filtrage par auteur, genre ou titre
  • Interface responsive avec Tailwind CSS / Bootstrap
  • Base de données MySQL gérée via Eloquent ORM
  • Déploiement sur instance EC2 AWS

Technologies utilisées

Laravel PHP 8 MySQL Tailwind CSS AWS EC2 GitHub
