Projet 2 AWS EC2

Déploiement d'un serveur web sur AWS EC2

Réalisé en 2026  |  Groupe 1 AWS re/Start

Description du projet

Ce projet met en pratique les bases du cloud AWS à travers le lancement d'une instance EC2, la configuration de la sécurité réseau et le déploiement d'un serveur Apache accessible depuis le web.

Dans ce travail de groupe, nous avons déployé un environnement web sur Amazon EC2 afin de comprendre le cycle complet de mise en ligne d'un service dans le cloud. Le projet nous a permis de manipuler la création d'instance, la connexion distante, la configuration système et l'ouverture des ports utiles.

Étapes réalisées

  • Création de l'instance EC2 (choix AMI, type, clés)
  • Configuration du Security Group (SSH + HTTP)
  • Connexion SSH et mise à jour du système
  • Installation et démarrage d'Apache
  • Test d'accessibilité via l'IP publique
  • Validation et documentation du déploiement

Technologies utilisées

Amazon EC2 Linux SSH Apache Security Groups
