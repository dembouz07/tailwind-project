Projet 1 Web App

Application de gestion des étudiants

Réalisé en 2026  |  Groupe 1 AWS re/Start

Description du projet

Ce projet consiste en le développement d'une application web de gestion des étudiants intégrant une gestion complète des utilisateurs et une base de données SQL Server. L'application permet de centraliser et gérer efficacement les informations relatives aux étudiants.

L'interface intuitive offre des fonctionnalités d'inscription, de consultation et de modification des données étudiantes, avec un système d'authentification sécurisé et une gestion des droits d'accès.

Fonctionnalités principales

  • Authentification & gestion des utilisateurs
  • CRUD complet des données étudiantes
  • Recherche et filtrage des étudiants
  • Interface web responsive et moderne
  • Base de données SQL Server
  • Tableau de bord administrateur
